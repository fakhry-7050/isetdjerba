# ISET Djerba — Navigator Pro

Version améliorée du projet de carte interactive ISET Djerba.

## Structure
- index.html
- css/style.css
- js/app.js
- assets/iset-djerba-map.webp

## Fonctionnalités
- Design complet desktop + mobile
- Carte basée sur le plan RDC fourni
- Recherche instantanée
- Filtres: Departments / Rooms / Labs / Services
- Markers interactifs
- Fiche détaillée d'un lieu
- Focus automatique sur un lieu
- Zoom + / - + reset
- Drag / pan de la carte
- Route animée depuis l'entrée
- Mode fullscreen
- Guide utilisateur
- Responsive phone / tablet / PC
- Aucun serveur nécessaire

## Lancer
Garder la structure des dossiers puis ouvrir `index.html` avec Chrome, Edge ou Firefox.
